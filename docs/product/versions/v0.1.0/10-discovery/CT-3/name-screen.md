## Qualified Review Checklist

- Search exact, phonetic, plural, spacing, and visually similar forms.
- Search relevant trademark classes and common-law software use in every intended launch jurisdiction.
- Check corporate and assumed-name registers.
- Check domains, GitHub organizations, package scopes, container registries, app stores, and major social handles.
- Review translations, pronunciation, accessibility, and unintended meanings.
- Confirm the logo, icon, colors, typography, and tagline are distinct as a whole.
- Record accepted goods and services description, owner entity, jurisdiction scope, and monitoring plan.

The accepted public name must be recorded in DEC-003. A new candidate requires a new dated screen; it must not silently replace this recommendation.
