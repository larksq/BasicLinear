# OpenLinear v0.1.0

Version `v0.1.0` is the first governed release candidate for OpenLinear's core project, issue, and milestone management experience. Its product intent is defined by the [PMO corpus](../../../../pmo/index.md). Live work is tracked only in the project-local Control Tower v0.8 task store.

The lifecycle begins in [Discovery](./10-discovery/README.md). `CT-1` was canceled without outreach and superseded by the accepted statistical scope evidence in `CT-77`; `CT-2` completed the interaction baseline. Discovery and Sprint Planning are accepted for the one-owner, one-implicit-workspace/team, loopback Node/SQLite boundary. Integrated acceptance remains in `CT-12`, while public naming, licensing, and distribution remain gated by `CT-3` and `CT-13`.

The working name is not a cleared public brand. Linear is a read-only experience reference; it is not a runtime, provider, task authority, API, MCP integration, or source-code dependency.
