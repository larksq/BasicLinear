# v0.2.0 Discovery

Discovery converts the sponsor's hosted-product request into a bounded, evidence-labeled handoff. The five canonical outputs are [problem](./problem.md), [user research](./user-research.md), [market and competitor research](./market-competitor-research.md), [technical investigation](./technical-investigation.md), and [requirements analysis](./requirements-analysis.md).

The [source index](./source-index.md), [evidence index](./evidence-index.md), [outcome contracts](./outcomes.md), and [normalized Discovery package](./discovery-package.json) preserve traceability. The package is intentionally yellow rather than pretending that a new hosted product already has activation, collaboration, conversion, or automation baselines.

Discovery permits Sprint Planning and a bounded implementation handoff once the normalized package validates. It does not claim implementation, payment-provider activation, security acceptance, release readiness, or achieved outcomes.
