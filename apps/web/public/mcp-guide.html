Connect AI clients with MCP

Use Codex or Claude Code to read and manage a hosted BasicLinear workspace. MCP uses OAuth with PKCE. Sign in with Google, choose your workspace, and approve the scopes your client needs.

Your local SQLite workspace remains separate. Connecting an AI client does not upload or synchronize local data.

MCP endpoint: https://basiclinear.qiaosun.me/mcp

Codex

Run these commands in your terminal, then complete sign-in in your browser:

codex mcp add basiclinear --url https://basiclinear.qiaosun.me/mcp
codex mcp login basiclinear
codex mcp list

Codex MCP documentation

Claude Code

claude mcp add --transport http basiclinear https://basiclinear.qiaosun.me/mcp
claude mcp login basiclinear
claude mcp list

CLI login requires Claude Code 2.1.186 or later. On older versions, open Claude Code, run /mcp, and select BasicLinear to sign in.

Claude Code MCP documentation

Choose your access

After signing in, select the workspace and review the requested scopes before approving. BasicLinear checks workspace membership and permissions on each call. A personal access token is not needed for this OAuth flow.

Start with a read-only request: “Use BasicLinear to list the workspaces I can access. Do not change anything.” Before updates, ask your client to read the current issue revision.

Using your own deployment

This page uses the current deployment’s domain in its setup commands when JavaScript is enabled. You can also find your deployment’s endpoint in the workspace’s “Use BasicLinear with AI” guide. Check the domain before connecting.
